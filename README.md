# MARMIT-2 Wet Soil Reflectance Explorer

### ▶ [Open the app](https://saremnorouzi.github.io/marmit2-explorer/)

An interactive browser app for the MARMIT-2 model (Dupiau et al., 2022, *Remote Sensing of Environment*, 272, 112951, [doi:10.1016/j.rse.2022.112951](https://doi.org/10.1016/j.rse.2022.112951)). Move the sliders to see how water-layer thickness (L), wet surface fraction (ε) and particle fraction (δ) change soil reflectance from 400 to 2400 nm. Nothing to install. A **Download for offline use** button is in the app.

Reflectance matches the official MARMIT-2 Python code to machine precision.
